# Legal Agent — what the DEMO needs. Not the library.

# To use the library, install the package instead and ignore this file:
#
#     pip install .              # verifier + retrieval; the corpus ships inside
#     pip install .[demo]        # + the Gradio app
#     pip install .[dev]         # + pytest and ruff
#     pip install .[anthropic]   # + the paid model backend
#
# pyproject.toml is the authoritative dependency list. This file stays because
# Hugging Face Spaces builds from it, and pinning the demo's runtime set
# explicitly is worth the small duplication: a broken build on the Space is
# invisible until somebody opens the page.
#
# Python 3.10+ (uses `X | None` type hints and dataclasses).
# ─────────────────────────────────────────────────────────────────────────────

# ── Retrieval (spec §2.2 Mechanism 1) ── [pinned; behaviour-sensitive]
rank-bm25==0.2.2         # Lexical BM25 over the corpus; strong on exact legal terms and article numbers. No GPU, no model download.
jieba==0.42.1            # Chinese word segmentation; BM25 needs tokenized Chinese text.
numpy>=1.24              # Dense-index arithmetic; also arrives transitively with rank-bm25.

# ── Web demo (app.py, and the Hugging Face Space) ──
gradio>=4.0.0            # Zero-key demo UI (verifier playground / retrieval explorer / five-gate flow); the Spaces entry point.

# ── Deliberately absent ──

# with no model at all, which is the point.
